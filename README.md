# cdn explorer

A password-protected **admin/cleanup UI** for the personal R2 CDN (`cdn.ramonfabrega.com`).
Companion to the `share` CLI: `share` writes objects (namespaced, with extensions), this finds /
previews / prunes / re-organizes them. `share` already returns the URL, so this is for
*managing* what's there — not grabbing the link you just made.

Runs as a **Cloudflare Worker** (Hono + R2 binding). The `share` CLI stays on Bun + the S3
client; the two share only the pure `lib/cdn.ts`.

## Files

- **`lib/cdn.ts`** — pure helpers (MIME map, key→ext classify, key-gen, URL/size formatting).
  Zero deps, no runtime-specific imports (own `extname`, Web `crypto`) → runs on Bun **and** Workers.
- **`worker.ts`** — the Worker. Hono `<{ Bindings: Env }>`: password gate (signed cookie),
  `/api/tree` + `/api/folder|move|rename|delete` (move/delete take a single key or batch `keys[]`).
  `GET /` reads `index.html`/`styles.css`/`app.js` from the **`ASSETS`** binding and inlines them into
  one self-contained document (no render-blocking subrequest → no FOUC, even on GPRS). `no-store`.
- **`storage.ts`** — R2 ops over the **`BUCKET`** binding: `tree()`, `createFolder`, `move`,
  `rename`, `remove`. Each takes the bucket (per-request `env`). Move/rename are copy+delete.
- **`r2-client.ts`** — Bun S3 client, creds via `passage`. **CLI-only** now (`bin/share`); the
  Worker never touches it.
- **`wrangler.jsonc`** — Worker config: R2 binding, `assets` (`run_worker_first` → the gate covers
  them), secrets. `Env` is generated by `wrangler types` (gitignored `worker-configuration.d.ts`).
- **`public/`** — vanilla, event-delegated, zero-build UI: `index.html` + `styles.css` + `app.js`
  (separate on disk; the Worker folds them into one response). Left **folder rail** (scope by prefix)
  · flat sortable/searchable list · ⌘K search · `⋯`/right-click menus · centered modals · animated delete.

## Run locally

```bash
cd cdn
bun install
bun run types          # generate worker-configuration.d.ts (Env) — rerun when bindings change
bun run dev            # wrangler dev → http://localhost:8787, local R2 sim + .dev.vars
```

`.dev.vars` holds `CDN_PASSWORD` / `CDN_SESSION_SECRET` for local dev (gitignored).

- `bun run test` — `vitest` in workerd: `lib/` units + `storage.ts` against a **local Miniflare R2**
  (`@cloudflare/vitest-pool-workers`, per-test isolation). Hermetic — no real R2, no `passage`.
- `bunx biome check --write .` — format + lint (config in `biome.jsonc`).
- Two tsconfigs (Bun + Workers globals collide): `tsconfig.json` (Worker) · `tsconfig.cli.json` (`r2-client`).

## Deploy

```bash
wrangler login
wrangler secret put CDN_PASSWORD
wrangler secret put CDN_SESSION_SECRET
bun run deploy         # → cdn-explorer.<subdomain>.workers.dev
```

Custom domain: add a `routes` entry to `wrangler.jsonc` (see the commented example) once the host's
DNS is on this Cloudflare account, then redeploy.

## Conventions

- Namespace by project (`cuanto/`, `test/`, …). Empty folders = a hidden `.keep` marker.
- Classify by **key extension only** (no content-type inference) — the CLI guarantees extensions.
- Move/rename change the key → **the public URL changes**; the UI confirms.
- 30-day expiry is planned as an **R2 lifecycle rule** (prefix-scoped), not app code.
